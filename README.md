# Kontopanagioti Pharmacies Website

Modern website for the Kontopanagioti pharmacies in Volos, Greece. The site presents the two pharmacy locations, opening hours, directions, contact options, social links, services, and real store photography in a clean responsive layout.

## Features

- Responsive React website built with Vite
- Dedicated sections for the two pharmacy locations
- Weekly opening-hours view with today's day highlighted
- Google Maps embeds and directions links
- Contact cards with phone and social media links
- Real store photos from the pharmacy locations
- Mobile call bar for quick contact on small screens

## Tech Stack

- React
- Vite
- CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Structure

```text
src/
  assets/       Store photos and visual assets
  components/   Reusable React sections and UI pieces
  data/         Pharmacy details, contact info, schedules, and services
  utils/        Schedule helpers
```

## Notes

Generated files such as `dist/`, `node_modules/`, and `.npm-cache/` are ignored and should not be committed.
